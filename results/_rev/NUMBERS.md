## Panel-width scan, shuffled labels (`dscan_null.json`, `_rev_night.py dscan_null`, seed 71 + 1000*cohort + d)

This is the quantity that locates the floor: on shuffled labels every returned edge is an
artefact, so the transition from cohorts that still return edges to cohorts that return none
brackets the identifiability boundary at that width.

| d | total edges on shuffled data | Pearson r(n, edges) | max n still returning edges | min n returning none | n*/d |
|:--|:--|:--|:--|:--|:--|
| 50 | 189 | -0.333 | 79 | 80 | 1.6 |
| 100 | 692 | -0.52 | 122 | 156 | 1.56 |
| 150 | 807 | -0.548 | 172 | 173 | 1.15 |
| 200 | 843 | -0.593 | 196 | 187 | 0.94 |

The ratio is not constant across widths, which is why the manuscript states the floor as a
boundary measured at each width rather than as a fixed multiple of d.  The original single-
width shuffle reported in `results/_shared_panel_notears.json` gives n = 156 / 172 at d = 100;
the rerun above, at a different seed, gives n = 122 / 156 at the same width.
